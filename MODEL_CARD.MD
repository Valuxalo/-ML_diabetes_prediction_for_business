# Карточка модели: Предсказания диабета на основе Случайного леса

## 1. Детали модели:
- Название модели: Модель предсказания диабета (Случайный лес)
- Версия 2.0
- Тип модели: бинарная классификация
- Фреймворк: scikit-learn
- Статус проекта: образовательный/пет-проект
- Основная задача: Оценить вероятность принадлежности пациента к группе риска заболевания диабетом.

## 2. Предполагаемое применение модели:
- Демонстрация полного цикла работы модели.
- Эксперименты с метриками и выбор итоговой модели.
- Демонстрация контейнеризации Docker и приложения streamlit.
- Диагностика диабета страховыми компаниями для принятия решения о страховании.
- Принятие клиинческих решений и рекомендации по лечению.
- Ускоренный скоринг пациента для клинической оценки пациента.

❗ВАЖНО❗ Данная модель **не заменяет** полную диагностику врача и не ставит окончательный диагноз. Она только предсказывает вероятность и лишь даёт оценку, которая требует проверки медицинским работником.

## 3. Обучающие данные
- Датасет: взят из открытого источника https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset
- Признаки и целевая переменная:
В notebooks `eda.ipynb` описана работа с датасетом. Размер датасета `(100000, 9)`. Всего 8 признаков:
    - Пол пациента
    - Возраст пациента
    - Артериальная гипертензия (наличие)
    - Сердечно-сосудистые заболевания (наличие)
    - Курение
    - ИМТ
    - Гликированный гемоглобин
    - Уровень глюкозы в крови

Последний столбец `diabetes` - целевая переменная: 0 - нет диабета, 1 - есть диабет.
Наличие диабитеа является минорным классом, по размерности в 10 раз меньше мажоритарного класса.

- Разделение выборки:
Используется разделение выборки на обучающую и тестовую с соотношение 0.2 для тестовой выборки. Набор для валидации отсутствует.

## 4. Архитектура модели и обучение:
Реализон единый pipeline со всеми этапи обучения модели и сохранения артефактов.

Выбранная модель - Random Forest (случайный лес). Полученные гиперпараметры:
```
n_estimators=100,
bootstrap=False,
class_weight="balanced",
criterion="gini",
max_depth=10,
max_features="log2",
min_samples_leaf=1,
min_samples_split=2
```
Также в процессе обучения сравнивались и другие модели: логистическая регрессия, дерево решений и XGBoost. Сравнение данных моделей приведено в notebook `ML.ipynb`. Показатель полноты (recall) был важным критерием выбора, поскольку ложноотрицательные результаты могут иметь последствия в контексте скрининга диабета.
Окончательный выбор также учитывал баланс метрик, а не опирался только на полноту.

## 6. Ограничения и риски
- Репрезентативность набора данных: производительность может варьироваться в зависимости от демографических групп, медицинских учреждений и популяций, не представленных в обучающих данных.

- Смещение распределения: производительность может снижаться при применении к данным,
собранным в различных условиях.

- Отсутствие клинической валидации: Модель не проверялась на клинических данных и не была признана безопасной или эффективной для клинического использования.
